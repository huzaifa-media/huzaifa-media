Privacy Policy — Huzaifa Media

Last updated: October 11, 2026

1. Overview

Huzaifa Media is a personal content-scheduling tool used by a single person — its owner — to publish the owner's own videos to the owner's own TikTok account. This policy explains what data the tool handles.

2. Data we collect

The tool handles only the following, strictly to operate the scheduling feature:

  • TikTok account identifier and access token — obtained once via TikTok Login Kit (user.info.basic scope) to authenticate the owner's account. Stored securely on the operator's own server and never transmitted anywhere else.
  • Video files and captions provided by the owner — uploaded to TikTok via the Content Posting API (video.upload and video.publish scopes) at the owner's scheduled times.

3. Data we do NOT collect

We do not collect data about any other person. We do not access other TikTok accounts, followers, messages, analytics of other users, or any third-party data. There is no public user base, no analytics SDK, and no advertising.

4. Data sharing

We do not sell, rent, or share any data with third parties. The only external transmission is the owner's own video content and captions sent to TikTok's official API for publishing to the owner's own TikTok profile, which the owner explicitly requests by scheduling a post.

5. Data storage and security

Access tokens are stored on the operator's private server and are never exposed publicly. The owner may revoke TikTok access at any time from TikTok's settings, which immediately stops the tool's TikTok functionality.

6. Data retention and deletion

Video files are deleted from the server after successful publishing. Access tokens are deleted when the owner disconnects the TikTok account or deletes the tool.

7. Children's privacy

This tool is not offered to the public and has no users under any age. No children's data is collected.

8. Changes to this policy

If the tool's data handling changes, this policy will be updated and the new date noted above.

9. Contact

Privacy questions can be directed to the tool's operator through the TikTok developer account associated with this application.
